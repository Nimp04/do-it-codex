## 3. 논의 내용과 결정 사항 (이유 포함)
### 타 팀 기여
- 2팀 PR #66 처리
  - 리뷰 단계에서 우리 팀 작업과 충돌을 예상했으나, 먼저 병합하고 우리 쪽에서 충돌을 해결하기로 결정
  - 이유: 외부 기여자가 우리 코드 구조를 파악해 충돌을 해결하는 것보다, 코드를 아는 우리 팀이 각자 담당 파일에서 해결하는 편이 빠르고 안전함
  - 파일별 충돌 해결
    - item.py: 양쪽 브랜치가 같은 이단 점프 버그를 각자 수정 → 속도 보정(+200)과 설명 주석이 정리된 PR 쪽 코드로 통일
    - player.py: 스프링 발판 2배 점프와 착지 애니메이션 상태가 같은 위치에서 수정됨 → 두 기능 모두 유지, 테스트용 모의 객체에 type 속성이 없어도 동작하도록 getattr로 보완
    - render.py: 스프링 발판 색상 추가와 장애물·플레이어 렌더링 개선이 겹침 → 스프링 색상은 유지하고 장애물·플레이어는 새 렌더링 함수(draw_obstacle, draw_player) 사용
    - level_design.py: 스프링 발판 확률 상수와 발판 속도 상수 정의 위치가 겹침 → 두 상수 모두 유지, 기존 속도 단계 상수 제거
- 4팀 #41: 풀 리퀘스트 제출 → 4팀 병합 → 4팀 main 반영까지 확인 완료
