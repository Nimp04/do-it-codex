do-it-codex 팀 프로젝트의 회의록을 저장하는 폴더입니다.

## 정기 회의

- 일정: 매주 수요일 21:30~23:00
- 방식: Discord 온라인 회의
- 문서 담당: 장여민
- 저장 형식: `YYYY-MM-DD.md`

## 회의록 구성

각 회의록에는 다음 내용을 기록합니다.

1. 지난주 결정 사항 점검
2. 팀원별 진행 상황 및 막힌 점
3. 논의 내용과 결정 사항
4. 다음 주 할 일과 담당자
5. 팀원별 활동 로그
6. 해당 주차 점검표

결정 사항은 결과만 기록하지 않고 가능한 경우 결정 이유도 함께 기록합니다.

GitHub Issue, Pull Request 등 관련 기록이 있는 경우 번호 또는 링크를 함께 남깁니다.
