## 2. 소통

- 응답 : 채팅 당일 읽는 즉시, 풀 리퀘스트 리뷰 48시간
- 답변 : 기본 당일까지, 개인사정시 상호합의
## 3. 작업 규칙
- 작업 전 이슈 등록 및 카카오톡 채널 통보, 하루 작업 끝에 Push
- 작업시 각자 맡은 파트의 branch 이용
- 브랜치·커밋·풀 리퀘스트 규칙은 안내서 8장
{
1. main 브랜치에는 직접 커밋을 올리지 않는다 (동시에 작업하면 꼬인다)
2. 기능 개발을 하기 전에 main 브랜치 기준으로 새로운 브랜치를 만든다
3. 브랜치 이름은 feature/기능이름 형식으로 하고, 한 브랜치에는 한 명만 커밋한다
4. 기능 개발이 끝나면 풀 리퀘스트로 main 에 합친다 (9 주차부터는 승인 1 개가 있어야 병합됨)
}
- main.py·공통 파일을 고칠 때는 이슈 댓글로 먼저 알림 + 카카오톡 이용
