## 담당 역할

- 풀 리퀘스트 리뷰 (팀 약속 기준 48시간 내 응답)
- 코드 품질·컨벤션 점검, 병합 전 동작 확인

## 개발 담당

- `hud.py` — 화면 상단 정보 표시 (점수, 목숨, 남은 아이템 등)
- `item.py` — 아이템 생성·획득 처리

## 자기소개

컴퓨터인공지능학부 24학번 김진우입니다. 이 팀에서는 HUD와 아이템을 개발하고,
팀원들이 올린 풀 리퀘스트를 병합 전에 한 번 더 걸러내는 리뷰를 맡았습니다.
빠르게 많이 쓰는 코드보다 다음 주에 읽어도 이해되는 코드를 선호합니다.
